## 三、启动与验证步骤

在项目根目录依次执行：

```sh
npm ci
npm run check:base
npm test
npm run typecheck
npm run build
npm run dev
```

- `GET http://127.0.0.1:4780/vue.html` 返回 200，页面渲染出 `h1`。
