## 一、关键差异与判断依据
1. **函数返回结构**：以工程给定骨架为准——返回 `{ value, errors }`，`value` 为清洗后对象或 `null`，`errors` 为 `{ field, code }` 数组；未使用自定义的 `ok / data` 结构。
2. **描述字段规则**：`description` 允许为空，只校验上限 1000 字符；标题 `title` 必填，长度 1–60。
3. **分类拼写修正**：反例中字段名统一为 `category`，避免拼写错误导致测试匹配不上。
4. **身份模拟**：基线通过 `X-Training-Actor` 请求头传入固定身份（user-01／user-02、staff-01／staff-02、manager-01），不是真实登录鉴权。
