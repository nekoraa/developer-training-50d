# Q02 编码记录
## 需求
实现 parseBranch 函数，接收分支名字符串，解析 `kind/task/slug` 三段结构；
规则：
1. 自动去除输入首尾空格
2. 必须以 `/` 分割，分割后刚好3段
3. kind 只能是 feat / fix / refactor
4. kind、task、slug 任意一段不能为空字符串
5. 校验失败返回 null，成功返回解析对象

## 实现思路
1. 使用 trim() 清除首尾空格
2. split('/') 切割字符串得到数组
3. 判断数组长度是否等于3，不等于直接返回null
4. 数组解构，取出 kind、task、slug
5. 白名单校验 kind 是否合法
6. 校验三段都不为空字符串
7. 全部校验通过，返回 {kind,task:task.toUpperCase(),slug} toUpperCase转大写
