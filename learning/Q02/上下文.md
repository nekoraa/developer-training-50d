# Q02 上下文
# 任务目标
  Q02为版本管理与提交审查练习。需要从Q01最终提交新建分支，练习规范的Git交付流程，同时实现parseBranch分支解析函数，自己补充3个边界反例。

# 编码规范 parseBranch
  格式为kingd/qNN-slug
  king仅允许 feat / fix / refactor 三个
  NN 范围是01-20
  slug 由小写字母开头，数字词段以单个短横线分隔：不能连续横线或尾横线。
  QNN是分支字符串，所以合法返回{king,task(大写Qxx),sulg},失败返回null
  接收字符串，输入的时候不调用函数trim()
